# VN VietTrip 2.0

베트남 도시별 관광지, 여행 코스와 여행 팁을 제공하는 반응형 정적 웹사이트입니다.

## 주요 기능
- PC / 태블릿 / 모바일 반응형 디자인
- 도시 검색 및 북부·중부·남부 필터
- 인기 관광지 검색 및 지역 필터
- 브라우저 기반 나만의 여행 일정 생성
- 일정 선택값 localStorage 저장
- 모바일 메뉴 및 현재 페이지 강조
- 외부 이미지 오류 시 자동 대체 이미지 표시
